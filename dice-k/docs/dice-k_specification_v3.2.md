## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | `dice-k` |
| 장르 | 다이스 워즈 스타일 주사위 땅따먹기 보드게임 |
| 목적 | 게임을 하면서 대한민국 시·군의 위치와 **공간적 인접성(맞닿은 이웃, 연결)**을 자연스럽게 익히는 에듀테크 웹 게임 |
| 대상 지역 | **대한민국(남한)만**. 북한 제외 |
| 배포 | `dice.geois.my` · PC/모바일 웹 반응형 |
| 플레이 방식 | **한 기기에서 번갈아 하는 방식(핫시트)**. 온라인 멀티플레이, 서버, 로그인 없음 |
| 후속 게임 | `dice-w`: 규칙은 같고 지도만 세계지도로 바꾼 **별도 게임** |

### 1.1 톤앤매너 [확정]

- '공격', '방어'는 보드게임 용어로 **사용한다**.
- '전쟁', '전투', '배틀', '군대', '지원군', '적군' 같은 말은 **사용하지 않는다**.
- 교육적이고 유익하되 쫄깃한 재미를 추구한다.

### 1.2 용어집 [확정]

| 게임 내 용어 | 의미 | 사용 금지 표현 |
|---|---|---|
| **칸** (지역) | 지도의 한 시·군 단위 | — |
| **주사위** | 각 칸의 힘. 그냥 "주사위"라고 부름 | 에너지 |
| **공격** | 내 칸에서 이웃 칸을 차지하려고 주사위를 굴림 | 전투, 배틀 |
| **방어** | 공격받은 칸이 주사위를 굴려 지켜냄 | — |
| **주사위 충전!** | 차례가 끝날 때 새 주사위를 받는 보급 | 지원군, 에너지 충전 |
| **라운드** | 살아 있는 모든 플레이어가 한 번씩 차례를 마친 단위 | 턴(라운드 의미로) |
| **차례** | 한 플레이어가 행동하는 순서 | — |

## 2. 지도 데이터 [확정]

### 2.1 칸(지역) 단위 규칙

1. **특별시·광역시·특별자치시는 통째로 1칸.** 산하의 구와 군도 나누지 않는다.
   - 서울, 부산, 대구, 인천, 광주, 대전, 울산, 세종 → 각 1칸
   - 부산의 기장군, 대구의 달성군·군위군, 인천의 강화군·옹진군, 울산의 울주군도 모두 해당 광역시 1칸에 포함
   - 따라서 인천의 2026년 자치구 개편(제물포구·영종구·검단구)은 게임에 영향 없음. 영종도는 인천 칸의 일부
2. **도 아래의 시·군은 각각 1칸.** 일반구로 나누지 않는다.
   - 예: 수원, 용인, 고양, 성남, 창원, 청주, 천안, 전주, 포항 → 각 1칸
3. **제주특별자치도는 제주시, 서귀포시 2칸.**
4. **군위군은 대구 소속**(2023년 편입)이므로 대구 칸에 포함한다.

### 2.5 인접 판정 [확정]

- 데이터: **통계청 SGIS 행정구역(시군구) 경계**의 최신 기준연도. 이용 조건(공공누리 유형)은 개발 시 확인하고 출처를 표기한다.
- **변(선분)이 맞닿는 경우만 인접.** 꼭짓점 하나만 닿는 경우는 인접이 아니다.
- 바다나 넓은 하구·만을 사이에 둔 지역은 아래 **연결표(2.6, 2.7)**로만 잇는다.

### 2.6 다리·하굿둑 연결표 [기본값 · 데이터로 검증 필요]

SGIS 폴리곤 데이터상 섬 지역뿐만 아니라 **하구·만(Bay)을 사이에 두고 면이 떨어진 시·군**도 실제 도로(교량·하굿둑)로 이어져 있으면 인접으로 연결한다. 데이터를 가공한 뒤 **고립 칸 목록 및 육상 단절 구간**을 자동으로 뽑아 아래 목록과 대조하고 확정한다. 경계 데이터상 이미 맞닿아 있는 곳은 중복으로 넣지 않는다.

| 구분 | 칸 A | 연결 대상 (칸 B) | 근거 |
|---|---|---|---|
| 섬 연륙교 | 신안군 | 목포시, 무안군 | 압해대교, 김대중대교 |
| 섬 연륙교 | 진도군 | 해남군 | 진도대교 |
| 섬 연륙교 | 완도군 | 해남군, 강진군 | 완도대교, 고금대교 |
| 섬 연륙교 | 거제시 | 통영시, 부산 | 거제대교·신거제대교, 거가대교 |
| 섬 연륙교 | 남해군 | 하동군, 사천시 | 남해대교·노량대교, 창선·삼천포대교 |
| 하구·만 연결 | 군산시 | 서천군 | 금강하굿둑 (충청-호남 서해안 연결) |
| 하구·만 연결 | 평택시 | 당진시 | 서해대교 (수도권-충남 서북부 연결) |
| 하구·만 연결 | 여수시 | 고흥군 | 백리섬섬길 연륙·연도교 |
| 하구·만 연결 | 영광군 | 고창군 | 칠산대교 |

- 다리·하굿둑 연결은 **육지로 맞닿은 일반 인접과 완전히 같게** 취급한다. 규칙, 결과 표시, 하이라이트 모두 육지 이웃과 똑같다. 배 아이콘이나 별도 표시를 붙이지 않는다.
- 지도에는 실제 다리·하굿둑 위치에 **짧고 얇은 선**만 그려, 물길로 떨어져 보이는 두 칸이 이어져 있다는 것만 알 수 있게 한다.
- 데이터상으로만 구분(`type: "bridge"`)하고, 플레이어에게는 일반 인접으로 보인다.

### 2.7 뱃길 연결표 [확정]

- **울릉군**: 포항시, 강릉시, 동해시, 울진군
- **제주시**: 목포시, 완도군, 부산, 인천 (4곳 확정)
  - `충청호남제주`(목포·완도), `영남호남제주`(목포·완도·부산), `전국`(목포·완도·부산·인천) 모든 프리셋에서 고립 없이 균형 잡힌 해상 거점 역할을 수행하도록 4곳으로 확정한다.
  - 서귀포시는 제주시와 육지로 맞닿아 있으므로 별도 뱃길은 두지 않는다.
  - 향후 밸런스 조정 여지를 위해 맵 팩 JSON 설정 파일(`links`)에서 수정 가능한 구조를 유지한다.
- 뱃길도 일반 인접과 같게 취급하며, 지도에는 바다 위 곡선 점선과 배 아이콘으로 표시한다.

## 3. 로비 · 게임 설정 [확정]

### 3.1 설정 항목

1. **맵 선택**: 2.4의 9종 중 1개
2. **총 인원**: 4~8명
3. **사람 플레이어 수**: 1명 ~ 총 인원. 나머지는 AI가 채운다
4. **플레이어별 설정**: 닉네임, 고유 색상, 고유 **무늬/아이콘**
5. **게임 모드**
   - **주사위 5개 모드**: 칸당 주사위 최대 **5개** (빠른 템포, 가벼운 암산)
   - **주사위 8개 모드**: 칸당 주사위 최대 **8개** (깊이 있는 전략)

### 3.2 색약 배려 (유니버설 디자인)

- 플레이어를 색깔만으로 구분하지 않는다. 각 플레이어마다 **고유 무늬(패턴) 또는 아이콘**을 칸과 주사위 배경에 함께 표시한다.
- 8개 색상은 색약 시뮬레이션으로 서로 구분되는지 검증한 팔레트를 쓴다.
- 같은 색이나 같은 무늬를 두 명이 고르지 못하게 막는다.

## 4. 게임 규칙

### 4.1 게임 시작 [기본값]

1. **턴 순서**: 랜덤으로 정하고 시작 화면에 1번~N번을 보여 준다.
2. **칸 분배**: 맵의 칸을 랜덤으로 균등 분배한다. 나누어떨어지지 않으면 **뒷순번부터** 1칸씩 더 준다.
3. **초기 주사위**: 모든 칸에 최소 1개. 플레이어별 초기 주사위 총량은 `보유 칸 수 × 2`이며 자기 칸에 랜덤 배분한다(칸당 최대 개수 준수).
4. **후공 보정 주사위**: 4.4의 표에 따라 추가로 랜덤 배치한다.

### 4.2 공격 · 방어 및 조작 단계 [확정]

1. **2단계 선택 후 실행 (오조작 방지)**
   - 모바일 터치 실수로 의도치 않은 공격이 실행되는 것을 막기 위해 **선택과 실행을 분리**한다.
   - **1단계 (출발 칸 선택)**: 주사위가 **2개 이상**인 내 칸을 탭한다. 공격 가능한 이웃 칸들이 하이라이트된다.
   - **2단계 (대상 칸 지정)**: 하이라이트된 이웃 적 칸을 탭하여 공격 대상으로 지정한다(두 칸 사이에 공격 화살표 표시).
   - **3단계 (실행)**: 하단 조작부의 **[주사위 굴리기]** 버튼을 탭하면 주사위가 굴러가며 결과가 즉시 확정된다.
2. **굴리기**: 공격 칸과 방어 칸의 주사위를 **모두** 굴려 눈의 합을 비교한다.
3. **결과**
   - **공격 성공** (공격 합 > 방어 합): 방어 칸을 차지한다. 공격 칸에는 주사위 1개만 남기고, 나머지(공격 주사위 수 − 1)는 새로 얻은 칸으로 옮긴다.
   - **방어 성공** (공격 합 ≤ 방어 합, **동점은 방어 성공**): 공격 칸의 주사위가 1개로 줄어든다. 방어 칸은 변화가 없다.
4. **행동 불능(공격 가능 칸 0개) 자동 안내**
   - 차례 시작 시 또는 공격 직후, **주사위가 2개 이상인 내 칸(또는 공격 가능한 이웃)이 하나도 없는 경우** 화면에 **"더 이상 공격할 수 있는 칸이 없습니다"** 안내 배너를 띄우고 하단의 **[차례 끝내기]** 버튼을 강조(점멸)한다.
5. 한 차례에 공격 횟수 제한은 없다. 플레이어가 **[차례 끝내기]**를 누르면 차례가 끝난다.
6. 보유 칸이 0이 된 플레이어는 **탈락**한다.

### 4.3 주사위 충전 (보급) [확정 · 상한은 기본값]

1. 차례가 끝날 때, 내 칸 중 **끊어지지 않고 서로 이어진 가장 큰 덩어리의 칸 수**만큼 주사위를 받는다.
   - "이어짐"에는 육지 인접(다리·하굿둑 포함)과 뱃길이 모두 포함된다.
2. 받은 주사위는 최대 개수에 도달하지 않은 내 칸에 **랜덤으로 1개씩 자동 배정**한다.
3. **저장 주사위** [확정]: 모든 칸이 가득 차서 놓지 못한 주사위는 저장해 둔다(원조 다이스 워즈와 같은 방식).
   - 다음 충전 때 **저장 주사위 + 새로 받은 주사위를 합쳐서** 빈 자리에 **랜덤으로** 배정한다. 플레이어가 직접 고르지 않는다.
   - 저장 상한: **64개**. 넘는 분량은 버린다.
   - HUD에 플레이어별 저장 주사위 개수를 표시한다.
4. 화면에 **"주사위 충전! +N"** 연출을 보여 주고, 가장 큰 덩어리를 잠깐 하이라이트해서 '연결 규칙'을 눈으로 보이게 한다.

### 4.4 후공 보정 [기본값]

먼저 하는 사람이 유리하므로, 뒷순번에게 **시작 보너스 주사위**를 준다(4.1의 초기 주사위와 별도로 랜덤 배치, 칸당 최대 개수 준수).

| 인원 | 1번 | 2번 | 3번 | 4번 | 5번 | 6번 | 7번 | 8번 |
|---|---|---|---|---|---|---|---|---|
| 4명 | 0 | +1 | +2 | +3 | | | | |
| 5명 | 0 | +1 | +2 | +3 | +4 | | | |
| 6명 | 0 | +1 | +1 | +2 | +3 | +4 | | |
| 7명 | 0 | +1 | +1 | +2 | +2 | +3 | +4 | |
| 8명 | 0 | +1 | +1 | +2 | +2 | +3 | +3 | +4 |

- **소형 맵**(수도권, 충청강원)에서는 표의 값을 **절반으로 하고 올림**한다. (+1→+1, +2→+1, +3→+2, +4→+2)
- 이 표는 시작값이다. 7장의 시뮬레이션에서 **순번별 승률 차이가 ±3%p 안에 들어오도록** 조정한다.

### 4.5 라운드와 승리 조건 [확정]

1. **1라운드** = 살아 있는 모든 플레이어가 한 번씩 차례를 마치는 것.
2. **15라운드**가 끝나면 게임 종료. 그 전에 한 명이 맵의 모든 칸을 차지하면 즉시 종료.
   - 15는 설정 상수로 둔다.
3. **등수 결정**
   1. 살아남은 플레이어: **보유 칸 수**가 많은 순
   2. 칸 수가 같으면: **보유 주사위 총개수**가 많은 순 (저장 주사위는 제외)
   3. 그래도 같으면: 공동 등수
   4. 탈락한 플레이어: 살아남은 플레이어보다 아래. **늦게 탈락할수록 높은 등수**
4. HUD에는 `라운드 7 / 15`처럼 표시한다.

### 4.6 등수 칭호 (수우미양가) [확정]

1등은 항상 **수**, 꼴찌는 항상 **가**.

| 인원 | 1등 | 2등 | 3등 | 4등 | 5등 | 6등 | 7등 | 8등 |
|---|---|---|---|---|---|---|---|---|
| 4명 | 수 | 우 | 미 | 가 | | | | |
| 5명 | 수 | 우 | 미 | 양 | 가 | | | |
| 6명 | 수 | 우 | 우 | 미 | 양 | 가 | | |
| 7명 | 수 | 우 | 우 | 미 | 미 | 양 | 가 | |
| 8명 | 수 | 우 | 우 | 미 | 미 | 양 | 양 | 가 |

칭호 설명 문구:

- **수(秀)** 가장 뛰어나고 훌륭함 🌟
- **우(優)** 넉넉하고 우수함
- **미(美)** 훌륭하고 아름다움
- **양(良)** 어질고 괜찮음
- **가(可)** 충분히 가능성이 있음

공동 등수는 높은 쪽 칭호를 함께 받는다.

### 5.1 화면 레이아웃 [확정]

**세로 모드 (모바일 기본)**

- 하단 고정: 선택 정보, **[주사위 굴리기]**, **[차례 끝내기]** 바

**가로 모드 (태블릿 / PC)**

- 좌측 사이드 패널: 순위표, 현재 차례 정보, 액션 버튼
- 우측(나머지 전체): 지도
- 2단 구성

### 5.2 HUD 표시 항목

- 라운드 `N / 15`
- 현재 차례 플레이어 (색 + 무늬 + 닉네임)
- 플레이어별: 보유 칸 수, 주사위 총개수, 가장 큰 연결 덩어리 크기, 저장 주사위
- 전체 판도 막대 (플레이어별 점유 비율)

### 5.3 지도 조작

- PC: 마우스 휠 줌, 드래그 팬, 클릭 선택
- 모바일: 핀치 줌, 한 손가락 드래그 팬, 탭 선택
- 드래그와 탭을 확실히 구분한다(이동 거리 기준).
- 작은 칸도 누를 수 있도록 확대 상태를 고려해 터치 판정을 한다.

### 5.4 지역 이름표 [확정]

**줌 단계별 표시**

| 줌 단계 | 표시 |
|---|---|
| 축소 (전국이 한눈에) | 도 이름만 |
| 중간 | 이름이 칸 안에 들어가는 지역만 |
| 확대 | 모든 지역 이름 |

- 이름표 켜기/끄기 토글을 제공한다(기본값: 켜짐).
- 이름표끼리 겹치면 큰 칸의 이름을 우선 보여 준다.

**탭(클릭) 시 표시** — 교육 효과의 핵심

- 칸을 탭하면 **그 칸과 모든 이웃 칸의 이름을 줌 단계와 상관없이** 보여 준다.
- 이웃 칸은 하이라이트한다. 뱃길로 이어진 이웃은 뱃길 선도 함께 강조한다(다리·하굿둑 이웃은 육지 이웃과 똑같이 처리).
- 내 칸(주사위 2개 이상)을 탭하면 **공격할 수 있는 이웃 칸**을 따로 강조해서, 공격 대상 고르기와 "어디와 맞닿아 있나" 학습이 한 동작으로 이루어지게 한다.

### 5.5 주사위 표현 및 굴리기 연출 [확정]

- **줌 단계별 칸 위 주사위 표현 (겹침 방지)**
  - **축소·중간 줌 단계**: 구리시·과천시·계룡시 등 면적이 좁은 시·군에서 아이콘이 이웃 칸을 가리지 않도록, 칸 중앙(`labelPoint`)에 **숫자 배지(예: `5`)**로 간결하게 표시한다.
  - **확대 줌 단계**: 일정 배율 이상 확대되면 주사위 개수만큼 **쌓아 올린 모양**으로 전환하여 한눈에 많고 적음이 보이게 한다.
- **굴리기 조작**: 화면 하단의 **[주사위 굴리기]** 버튼을 **탭**하면 굴린다. 기기 흔들기(모션 API)는 쓰지 않는다.
- 또랑또랑한 주사위 소리와 굴러가는 애니메이션, 공격 합과 방어 합 비교 연출.
- 굴린 뒤 **공격 칸과 방어 칸 위에 각각의 합을 큰 숫자로** 겹쳐 보여 준다. 숫자는 해당 플레이어 색으로 표시한다.
- 결과 표시에는 **반드시 지역명을 함께** 쓴다. 'VS' 대신 **'옆'**을 써서 두 지역이 맞닿아 있다는 사실을 문장으로 보여 준다. 매 공격마다 "○○ 옆 △△"가 나와서 어디와 어디가 이웃인지 저절로 익히게 하는 핵심 학습 장치다.
  - 결과 배너는 2줄로 구성한다.
    ```
    거제  옆  부산
     4    :    6
    ```
    1줄: 공격 지역 **옆** 방어 지역 (이웃 관계) / 2줄: 각 지역 아래에 주사위 합 (승패)
  - 이긴 쪽 숫자를 강조(크게, 해당 플레이어 색)한다.
  - 화면 상단(또는 하단 조작부 위)에 결과 배너로 띄우고, 두 칸 위의 큰 숫자 연출과 동시에 보여 준다.
  - 지역명은 접미사 없이 짧은 이름을 쓴다(예: 수원, 청주, 서울, 울릉). 맵 팩의 `label` 값을 사용.
  - **뱃길**로 이어진 공격일 때만 '옆' 대신 **'⛴ 뱃길'**로 표시한다(예: "울릉 ⛴ 뱃길 포항"). 다리·하굿둑으로 이어진 공격은 육지와 똑같이 "거제 옆 부산"으로 표시한다.
- 사운드 켜기/끄기 제공.
- AI 차례에는 버튼 없이 자동으로 굴린다.

### 5.6 결과 팝업

- 공격 성공: **"○○시 획득!"** (군이면 "○○군 획득!", 광역시면 "부산 획득!")
- 방어 성공: **"○○군 방어 성공!"**
- 주사위 충전: **"주사위 충전! +N"**
- 게임 종료: 등수와 칭호, **"내가 차지했던 지역"** 목록과 지도

### 5.7 핫시트 차례 넘기기

- 사람 플레이어의 차례가 시작될 때 **"○○님 차례입니다"** 화면을 띄우고, 탭하면 시작한다(기기를 건네받는 시간).

## 6. AI · 저장 · 기술

### 6.1 AI [확정 · 세부는 기본값]

- **단순 탐욕 알고리즘**. 한 차례 계산은 0.5초 이내.
- 기본 판단 규칙:
  1. 내 주사위 수 > 상대 주사위 수인 공격을 우선한다.
  2. 같으면 내 주사위가 최대 개수일 때만 공격한다.
  3. 여러 후보 중에서는 **내 연결 덩어리를 이어 주거나 키우는** 공격을 우선한다.
  4. 할 공격이 없으면 차례를 끝낸다.
- 계산과 연출은 분리한다. 연출 속도는 **보통 / 빠르게 / AI 차례 건너뛰기** 중에서 고른다.
- AI 난이도는 1단계만 구현하되, 나중에 추가할 수 있는 구조로 만든다.

### 6.2 저장 · 이어서 하기 [확정]

- `LocalStorage`에 게임 상태를 **매 행동마다** 저장한다.
- 다시 접속하면 로비에서 **[이어서 하기]**를 보여 준다. 저장 슬롯은 1개.
- **새 게임 덮어쓰기 보호**: 저장된 진행 기록이 있는 상태에서 **[새 게임 시작]**을 누르면 **"진행 중인 게임 기록이 사라집니다. 새로 시작할까요?"** 확인 창을 띄운다.
- **새로고침으로 주사위를 다시 굴리는 꼼수를 막는다.** 주사위 결과는 버튼을 누르는 순간 확정하고 **저장한 뒤에** 애니메이션을 재생한다. 새로고침하면 이미 확정된 결과가 적용된 상태로 이어진다.
- 저장 데이터에 버전 필드를 두어 업데이트 후 호환되지 않는 저장은 안내 후 폐기한다.

### 6.3 엔진 구조 [확정]

- **게임 로직 엔진**(규칙, 상태, AI)과 **화면(UI)**을 완전히 분리한다.
  - 엔진은 화면 없이도 실행할 수 있어야 한다(7장 시뮬레이션에 사용).
- **지도 정보는 '맵 팩' 데이터로 분리**해서 엔진이 특정 지도에 의존하지 않게 한다. `dice-w`는 맵 팩만 바꿔 같은 엔진으로 만든다.

### 6.5 지도 데이터 가공 절차

1. SGIS 시군구 경계(최신 기준연도)를 받는다.
2. **합치기(dissolve)**
   - 특별·광역·특별자치시: 시도 단위로 1개 도형
   - 도 아래 시: 일반구를 시 단위로 1개 도형
   - 군위군은 대구에 포함
3. **단순화**: 모바일에서 가볍게 돌도록 꼭짓점을 줄이되, 이웃끼리 경계선이 어긋나지 않게 위상(topology)을 유지하는 방식으로 한다(예: mapshaper, TopoJSON).
4. **인접 추출**: 공유하는 경계선(arc)이 있는 쌍만 인접으로 기록한다. 꼭짓점만 닿는 쌍은 제외.
5. **검증 (자동)**
   - 칸 수 = 161
   - 고립 칸 목록 출력 → 2.6, 2.7 연결표로 모두 해소되는지 확인
   - 맵 프리셋별 칸 수가 2.4 표와 같은지 확인
6. **검수 (사람)**: 지역 이름과 인접 관계를 지리 교사가 확인한다. 교육용이므로 틀린 인접은 치명적이다.
7. 출처 표기: 게임 내 정보 화면에 데이터 출처와 기준연도를 표기한다.

### 6.6 기술 권장 사항

- SVG 기반 지도 렌더링(칸 161개는 SVG로 충분).
- 오프라인이나 느린 통신에서도 첫 로딩 후 동작하도록 정적 파일로만 구성한다(서버 불필요).
- 로그인, 개인정보 수집 없음. 닉네임은 기기 안에만 저장한다(학생 사용 고려).

### 8.1 전체 제작 순서 (권장)

1. **한반도 지도 색칠 웹앱**: 지도 가공, 칸 ID와 이름, 인접 데이터를 먼저 만든다. "이웃끼리 같은 색이면 경고" 기능으로 인접 데이터를 검수하는 도구로도 쓴다. `dice-k`는 여기서 **남한 부분만** 가져다 쓴다.
2. **dice-k**: 1의 맵 팩 + 게임 엔진
3. **세계지도 색칠 웹앱**: 세계 맵 팩 제작과 검수
4. **dice-w**: 3의 맵 팩 + `dice-k` 엔진
